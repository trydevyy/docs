# Devyy documentation

This repository contains the guides published at [www.devyy.dev/docs](https://www.devyy.dev/docs/). The website builds its navigation, search, sitemap, and Markdown exports from the files in `content/`.

See [Contributing](CONTRIBUTING.md) for the guide format, local preview instructions, and pull request checks. Use the [issue templates](https://github.com/trydevyy/docs/issues/new/choose) to report a problem or suggest a guide.
