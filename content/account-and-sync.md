A Devyy account is optional for local editing. Use one when you want to sign in on more than one device and sync supported editor preferences.

## Connect the desktop editor

1. Open **Account & sync** from Devyy.
2. Start sign-in in the browser. Use an existing account or create one. If you register with email, verify it with the code sent to that address.
3. Confirm the device shown by the browser, then choose **Open Devyy** to return to the desktop app.
4. Review the categories in **Account & sync** and choose what you want to sync.

The device authorization starts in the desktop app. If the browser says the link expired, start again from the app so it can generate a fresh request.

## Move to another device

Sign in to the same account on the second device, then review its sync preferences. Sync covers selected settings and extension information. Your project files remain in the local folder or on the SSH server where you opened them. Use your usual project transfer or Git workflow to make the project available on another device.
