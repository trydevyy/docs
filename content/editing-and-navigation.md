Open a folder before using project search or the explorer. The project tree works with files on disk. Unsaved editor changes stay in their tabs until you save them.

## Move around your project

Use the file picker when you know the filename and workspace search when you know text inside a file. Workspace search respects Git ignore rules and skips generated folders.

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Find a file | ⌘ P | Ctrl P |
| Run a command | ⌘ Shift P | Ctrl Shift P |
| Find or replace in the current file | ⌘ F | Ctrl F |
| Search across the workspace | ⌘ Shift F | Ctrl Shift F |
| Save the active file | ⌘ S | Ctrl S |
| Go to a line | ⌘ L | Ctrl L |

The file picker highlights matching parts of a path. Use the arrow keys to choose a result and **Enter** to open it. To review or change a binding, go to **Settings → Keyboard shortcuts** and search for the command.

## Work with two files

Right-click a different file in the explorer and choose **Open in split editor**. Drag the divider to adjust the space given to each file. Selecting a tab in the pair restores its split. Opening another tab shows that file on its own.

For Markdown files, use the source, preview, or side-by-side controls. You can keep editing the source while the preview updates.

## Set the Monochrome theme

Open **Settings → Appearance** and choose **Monochrome**. The theme uses black and neutral window surfaces with syntax colors for reading code. Use the appearance settings to adjust window and editor transparency independently.
